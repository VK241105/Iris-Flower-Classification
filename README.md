# 🌸 Iris Flower Classification

## 📌 Project Overview

This project uses Machine Learning to classify iris flowers into different species based on their flower measurements.

The classification is performed using the **K-Nearest Neighbors (KNN)** algorithm.

## 🎯 Objective

The objective of this project is to build a simple machine learning classification model that can predict the species of an iris flower using:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

## 📊 Dataset

The project uses the **Iris dataset** available through Scikit-learn.

The dataset contains three flower species:

* Setosa
* Versicolor
* Virginica

## 🛠️ Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib

## 🤖 Machine Learning Model

**Algorithm:** K-Nearest Neighbors (KNN)

### Workflow

1. Load the Iris dataset
2. Separate features and target labels
3. Split the data into training and testing sets
4. Train the KNN classifier
5. Make predictions on test data
6. Evaluate the model

## 📈 Model Evaluation

The K-Nearest Neighbors (KNN) model achieved an accuracy of:

**Accuracy: 93.33%**

### Classification Report

| Class | Precision | Recall | F1-Score |
|---|---:|---:|---:|
| Setosa | 1.00 | 1.00 | 1.00 |
| Versicolor | 0.83 | 1.00 | 0.91 |
| Virginica | 1.00 | 0.80 | 0.89 |
